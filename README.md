# CS172 Project — Web Crawler + Search Engine

A two-part course project:

- **Part A:** a Python web crawler that collects HTML pages starting from seed URLs and stores them locally.
- **Part B:** a Lucene-based index over the crawled pages plus a Django web app with a search box, ranked results, and relevance scores.
